# jawata-studio v4.6.11

**The studio hands the editor's folders to the engine, so a hired agent can work in them.** This release needs jawata-mcp 4.6.9.

## What changes

- **The editor's folders reach the engine.** When an editor launches the workspace, the studio records the folders it was handed and starts the engine with them (`JAWATA_WORKSPACE_FOLDERS`). A hired agent then sees the loaded projects and those folders, so a folder of your editor workspace that is no Java project can be worked on. Before, such a hire was refused as outside the workspace.
- **Seats.** Either the project manager or the chief engineer may hire the developer, and whoever hires it carries the boundary lines into the brief. The chief engineer and the test manager list `hire` among their tools, as the seat tree makes them hirers. The project manager writes its plan, its checkpoint records and its findings list itself, as files, and ends with the result and not with a brief file.

## Known limits

- The editor-folder path was shown in a sandbox on Linux; it was not run on Windows or macOS by hand (CI builds them).
- The studio itself was not shown in a real window for these changes.
