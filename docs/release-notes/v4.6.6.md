# jawata-studio v4.6.6

**The dashboard loads again.**

In 4.6.3 the dashboard did not answer within 60 seconds on a machine with many projects, showed "no workspaces yet", and the window could not be closed. Your workspaces were not removed; the list was empty because the load never finished.

## What changed

- **The studio asks npm where it installs commands once per start.** 4.6.3 asked it again for every project the dashboard loaded, about one second each. An agent program installed while the studio runs is found after the next start of the studio (4.6.3 found it after reopening the Seats tab).

4.6.4 and 4.6.5 were never published: their release builds stopped under the Rust build tools of 9 November, which this build does not use. Needs jawata-mcp 4.6.5 and the extensions 0.2.3, as 4.6.3 did.

## Known limits

- Checked on Linux on one machine: the studio with this change no longer starts npm repeatedly. Windows and macOS builds are produced but were not used by hand.
