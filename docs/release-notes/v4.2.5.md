# jawata-studio v4.2.5

One line of the dashboard, and it is the third release in a row found by using the
product rather than by a test.

## The status badge stops repeating a number that is already on screen

"Managed Projects" carried a badge reading **"33 OF 230 RUNNING"**. The line
directly beneath it reads *Workspaces 3 · Running 2 · Stopped 1 · **Projects 230***.

So the badge was spending most of its width restating the 230 — while sitting
immediately above it — and it did that next to the one number that appears nowhere
else on the screen.

It now reads **"33 running"**.

The two lines count different things and both are wanted: the pills count
**workspaces**, the badge counts **projects**. Two of three workspaces are running,
and within them 33 of the 230 projects are up. Dropping the total left the half that
is not otherwise available.

## Unchanged in this release

The badge's colours, which v4.2.4 introduced: solid green when everything runs, a
green ring on grey when some do, grey when none do, amber only when something is
actually wrong.
