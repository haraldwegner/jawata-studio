# jawata-studio v4.6.9

**The Seats page picks the listed model a saved model stands for.**

This release needs jawata-mcp 4.6.7.

## What you see

- **A seat whose saved model is a short alias, such as `sonnet`, shows the model the brain's own list names it by,** such as "Claude Code — Sonnet 5.5", with no "(not available on this machine)" tag. The first model of that family in the brain's list is the one picked.
- **A saved model nothing in the brain's list stands for shows the brain's own default model.** The stored value changes only when you pick one, and the page tests the pick with a one-word run before it saves.
- **The "(not available on this machine)" line appears only when the machine offers nothing of the brain at all,** for example it is not installed or cannot be hired.

## Known limits

- Checked on Linux: the tests and the release checks. The picking of the model is held by a test of the rule that maps a saved model to a listed one; the page itself was not looked at in a window by hand. Windows and macOS builds are produced but were not used by hand.
