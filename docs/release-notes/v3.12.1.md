# jawata-studio v3.12.1 — a gate that a correct run can pass

## The seat gate follows the edit, not the seat

The stop gate demanded a verification gate from any seat run — including
`/report`, which changes no code at all. A correct `/report` run therefore had
to declare its compile gate "inapplicable", and a gate that a correct run
cannot satisfy teaches agents to narrate around gates instead of running them.

The obligation now follows the **edit**: a seat run is held only when the turn
actually changed code.

Found while fixing it, and the worse half: seat detection matched the bare
command anywhere in the transcript, so a turn that merely *wrote about* the
seats — a report, a plan, a comment naming them — counted as having run them.
Seats are now read from your own message, where a slash command is typed, plus
any skill the agent launches itself.

## /report routes by what is actually broken

The seat chose its tracker from the failing tool's product, so every case where
the engine answered correctly and a **consumer** — a hook, a seat, the studio,
the deploy — misread or mis-routed that answer was filed against the engine,
because an engine tool's name is what appears in the recorded shape.

It now asks the consumer question first, and when the recording genuinely
cannot tell the two apart — it carries shapes, not content — it says so on the
review screen and lets you pick the tracker instead of guessing.

Closes **#17** and **#18**.
