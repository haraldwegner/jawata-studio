# v4.0.0 — the gate stops trusting what the agent writes about itself

**Two stops on the night of 2026-09-03 cost half a night's work, and both were
legal.** An unattended run was granted, the plan named exactly three moments
reserved for the human — the release, the patch, one scope question — and the
agent stopped twice at neither of them. Once to offer a release the plan
schedules five stages later. Once to report a refused checkpoint whose findings
it had already fixed and simply not re-run.

Both passed the gate, because the gate's exemption was a line the agent writes:
`DECISION:`. That marker had itself replaced a 42-phrase guess at the agent's
prose, after the guess slept a session for 21 minutes by matching "SAY THE
WORD". A declaration is better than a guess. It is still the agent's own text,
and an agent whose training rewards ending a turn well produces the mandated
format on the first attempt — no adaptation, nothing to detect.

Harald: *"YOU WANT TO STOP ALL THE TIME AND ARE TRAINED ON THE QUICK RESULT.
THIS IS NOT REALLY GOOD FOR LONG LASTING DEV TASKS!"*

## The judge

Under a live grant, a stop that armed no background work now goes to a
fresh-context subagent — the `autocontinue` seat, deployed to
`~/.claude/agents/autocontinue.md` and rewritten from the binary on every deploy
so the agent cannot soften the stance that judges it.

It is handed ONE line: the path of the transcript the session is writing. It
reads that itself — the agent's stop text, the plan the `slug` field names, the
gate results, the checkpoint reached — and answers one question:

    VERDICT: RESERVED
    VERDICT: RESOLVABLE — <the next action, one sentence>

RESERVED lets the stop through. RESOLVABLE holds it and the block carries the
seat's own next action, so the agent is told what to do rather than merely to
continue. On last night's second stop that sentence would have been *"the bugs
are fixed — re-run the two reviews and continue"*, which is one step the agent
already owned.

**The verdict is read from the harness's tool-result record, not from the
agent's prose.** Writing the line yourself buys nothing; that is the defect
being closed, and there is a test whose whole subject is that it buys nothing.

What is not claimed: the transcript is writable by the uid the agent runs as, so
a forged result would pass. That is a different act from phrasing a stop to fit
a rule, it is not the failure that has occurred here, and the honest bound is
the one this module's header already draws.

## A mention is no longer a command

`autocontinue` inside a sentence armed the grant. On 2026-09-03 the sentence was
*"Autocontinue worked 2-3 months ago without any hook"* — an argument that the
mechanism had regressed — and it pushed the agent into plan work mid-argument.
Quoted mentions were already handled; this is the unquoted one, which is the
ordinary way anyone refers to a thing by name.

The word must now END a line. That is syntax, not intent, and his own corpus
separates on it cleanly: every arming order he has typed finishes with the word
(*"work the plan and autocontinue"*), and every mention continues past it,
because a sentence about a thing goes on to say something about it.

## The communicator is retired

*"The communicator is annoying. I see the same output twice. It is not far away
from what is originally said. Can we instead add a ruling."*

The subagent that read every self-initiated upward message is gone. Measured
over a full session it caught three things — a reference he could not open, a
count with no object, an undefined term — and every one is a checklist item, not
a judgement. It cost its whole readback rendered to him beside the message it
was reviewing.

Three questions replace it, in the deployed instructions and in the length
rule's own block text: can he OPEN every fact · has this conversation DEFINED
every term · is the implementation detail BELOW the point.

**And the reason a ruling is enough here when it was not enough for stopping:**
a rule the agent applies to itself holds only where the agent has no motive to
break it. There is no reward in writing an unclear message. There is a reward in
ending a turn. Judge where there is a motive; rule where there is not.

The mechanical residual stays in the hook, because both halves are decidable
from the text with nothing to consult: over the length budget, and an undefined
abbreviation.

## Also

- **Rule B's condition had two hand-written copies** under a comment saying they
  must agree "character for character". That is not a mechanism, and this crate
  shipped a fix taught to one copy of a pair twice in one week. One function now,
  two callers.
- **The review ceiling could wall off its own exit.** It tells the agent to put
  an unconverged dispute to the judge, and then blocked the turn that did so. A
  RESERVED verdict is now honoured ahead of it, with the ordering pinned by a
  test.
- `hook-events.json` records the retirement rather than dropping the row, so a
  retired rule stays distinguishable from a deleted one nobody explained.

## Breaking

- A `DECISION:` line no longer ends a turn under a live grant. The judge does.
- The `communicator` subagent is no longer required or consulted by any gate.
  Its definition is left on disk untouched; nothing reads it.
- Cursor has no subagent facility, so the judge does not reach it. The gate
  holds on Claude Code; on Cursor a granted stop falls back to Rule B's
  empty-turn ceiling alone. Recorded as a real gap, not papered over.
