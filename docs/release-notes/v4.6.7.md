# jawata-studio v4.6.7

**Deploy says what it does to VS Code before it does it, and the chat names the model that is answering.**

This release needs jawata-mcp 4.6.6.

## What you see

- **The deploy panel has two lines.** Agents: Claude Code, Cursor, Codex, Copilot CLI and Grok, each given jawata's tools. Editor: VS Code, the host of the jawata chat, given the jawata chat and jawata Java.
- **Before you deploy, the panel says what happens in VS Code:** jawata Java takes over Java support, and Red Hat's Java extension is removed with the Extension Pack for Java and the extensions that need it. Untick VS Code to keep them.
- **VS Code's own Copilot stays switched off and is no longer given jawata's tools.** The entry an earlier deploy gave it is taken out. Copilot reaches jawata as Copilot CLI, on the agents line.
- **After a deploy, one sentence:** for how many agents jawata is set up, what was skipped or failed, and what happened in VS Code. What each step did is under Details.
- **With engine 4.6.6, the chat's brain row names the model that is answering** after you pick another brain, instead of the previous brain's model list.

## Known limits

- Checked on Linux: the tests, the release checks, and the dashboard rendered against test data. The installed studio window was not used for these changes. Windows and macOS builds are produced but were not used by hand.
