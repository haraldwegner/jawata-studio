# jawata-studio v4.4.8

**Every tab is cut down to what you decide or change, Lombok workspaces get the Lombok agent again, and a folder the search finds nothing in can still be added as a project.**

## What went wrong

- **The window showed far more than anyone reads.** Walked through on 4.4.7: Dashboard offered a dry run whose preview was never shown and a Regenerate that only skipped files already identical; Memory and Reporting opened on walls of figures with the working buttons at the bottom; Seats listed every seat in full; Settings mixed three subjects; Help was stale.
- **A Lombok workspace started without the Lombok agent.** The studio looked for Lombok in one project of the workspace and only downwards, while a multi-module build usually declares it in a parent pom or a `lombok.config` above the project. Combined with the 4.4.x engines shipping no `lombok.jar`, the java-design-patterns workspace reported 3,445 false compile errors, and nothing said why.
- **Removing the separate "Save project" path left no way to add a folder the search does not recognise** (no Maven, Gradle or Eclipse file), and Enter in the folder field did nothing.

## What changes

- **Each tab opens on one summary line with its main actions, and the rest folds.**
  - **Dashboard:** one deploy action, and project cards fold. A card with a problem stays open, and a project's path is in its mouseover.
  - **Memory:** the buttons sit at the top, its warnings stay above the folds, and the two store settings moved here.
  - **Reporting:** opens on one sentence saying whether anything needs a look. The figures and the per-channel list are folded.
  - **Seats:** grouped into the ones you type, the ones another seat hires and the ones inside `/sprint`. Each is one line with its switch.
  - **Settings:** folded into Engine, Agents and This machine. Agents is one table: an agent you switched off is greyed, and a config file that is missing or set by hand carries a badge.
  - **Help:** rewritten, with a gate that every tab has a section.
- **Add projects is one folder field that always searches.** When the search finds no project, **Add this folder as a project** adds the folder itself. Enter starts the search.
- **Lombok detection asks every project of the workspace, and looks upwards** (up to four directories) for a parent build file or a `lombok.config`.
- **A Lombok workspace on an engine without `lombok.jar` is logged** instead of being started without a word.
- **The release checks the published engine.** The studio's release job now checks that the engine download users install carries `lombok.jar` beside `jawata.jar`, the layout the studio depends on.
- **Menus are easier to reach and leave.** A context menu opened from the keyboard appears under the focused name, and menus close on an outside click or Escape.

## Known limits

- **That Lombok log line goes only to the resident's log file.** Showing the degradation in the engine's own answers is filed for Sprint 28h.
- **The keyboard route to Delete has not yet been checked by hand on the installed window.**

Works with jawata-mcp 4.4.13.
