# jawata-studio v4.2.0

Nineteen issues closed. Automatic engine updates become the real behaviour, the local
guards stop being Linux-shaped, and a shell write that reaches a `.java` file is caught by
its EFFECT rather than by how it was spelled.

## Automatic update is the default, and every check says what it decided

The engine now updates itself by default, and each decision — take it, ask, already current —
is reported rather than inferred. `auto_seed_on_deploy` no longer refills the store with the
pre-cutover corpus: the deploy ASKS the resident where its substrate lives and skips, loudly,
when it has none. A pathless load was the defect, so falling back to one would have
reintroduced it on exactly the configuration nobody checks.

## The guards

- **A `.java` write through a shell is detected by its effect** (#43) — an interpreter
  heredoc, a redirection, an in-place edit. Spelling-based detection was a list of ways to
  write a file, and the list was never complete.
- **The four local guards stop being Linux-shaped** (#38): `/tmp`, `~/.claude` and the
  credential rules now resolve on Windows and macOS instead of silently allowing.
- **The guard reaches the reading tools** (#41), and the gate rule gets an escape hatch that
  is declared rather than assumed.
- **The audit-fix-loop rule had two implementations with different predicates** (#42) — one
  required the verdict to start a line, the other counted the substring anywhere, so a
  session quoting the rule tripped one and not the other. They agree now, pinned from both
  ends.
- **The Cursor seat target writes where Cursor own documentation says** (#44), and stops
  listing every seat twice (#19).

## Windows and the runtime

- **A listening PID can be found on Windows** (#6, #7, #13) — the branch returned `None`
  unconditionally, so nothing that depends on finding a running service worked there.
- **Residents can be launched debuggable** (#29), off by default and loopback only, so
  jawata own debug and profile tooling can reach them at all.
- **Registering a large multi-module project no longer freezes the UI** (#27).
- **The go-silent state means what it says** (#22): stored per workspace, but it means per
  machine.

## Tests

A service-level harness exists (#45), so a `ManagerService` method wiring is provable rather
than assumed — and the first thing it proved was that a service built in a test could reach
the user own configuration. The backup area stops being a process global that parallel tests
race on (#46).

### Gates

The Rust workspace suite is green over the released tree: 840 passed, 0 failed, 7 ignored.
