# v3.16.2 — the loop counters reset at the boundaries of the loops they measure

Completes v3.16.1, which fixed *who counts as the human*. This one fixes *when
the counters forget* — found the same morning on one instruction: "the
conversation loop counter needs to be reset correctly. Double check!"

## Two broken reset semantics

**The audit-fix carry died at every notification window.** Each audit verdict
arrives as a background notification, and a notification opens a new window —
so the per-window refusal count reset between every round. The alarm built to
catch an overnight refuse-repair loop could never fire on that loop, while
firing happily on prose that merely discussed refusals (measured live: three
mentions of the word in a workflow conversation tripped it). The carry now
lives per session and resets on exactly three things: a real keyboard window
(the human is steering), a relayed `VERDICT: SIGN-OFF` (the loop converged), or
an architect-seat run (the action the alarm demands). It does not clear on an
allowed turn — repairs between refusals are allowed turns, and surviving them
is the point of a loop counter.

**The review ceiling was charged by every block.** Measured live: a Rule B push
wrote bounce=1, and the review rule's very first offence seven seconds later
read "(2 of 3)". Three unrelated pushes and an unjudged decision-ask sails
through at the cap — the exact leak the ceiling guards. Each counter is now
charged only by its own rule, as the reseed counter already was.

**And talking about refusing is not refusing.** The refusal detector matched
the substring anywhere in text; it now counts verdict lines only (`VERDICT:
REFUSE` at the start of a line, markdown decoration allowed) — the same
line-start principle the degradation stamp in the same file already states.

## Verification

Every reset boundary is pinned by a test that drives the real binary across
multiple invocations — the layer where all of these defects lived, invisible
to any test of the pure decision function: the alarm fires on the third
refusal across notice windows; a sign-off resets it; a keyboard window resets
it; a Rule B push leaves the review ceiling untouched. Full hook suite: 258
unit tests plus 19 integration suites, zero failures.
