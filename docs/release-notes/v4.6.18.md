# jawata-studio v4.6.18

**Antigravity (`agy`) is a deploy target and a brain, Grok leaves the roster and Cursor is shown as Cursor-Grok, agents are listed A to Z, a brain that is not connected has a Connect button, and one small bar shows the version each running engine reports.** This release needs jawata-mcp 4.6.14 and goes with jawata-chat 0.2.14.

## What changes

- **Antigravity.** A deploy writes the jawata servers into Antigravity's MCP config (`mcp_config.json` in its Gemini config folder in the home folder), the Seats page and the chat offer it as a brain, and Agent Control lists it. Grok has no row (it is merged with Cursor); Cursor reads Cursor-Grok. Agent lists are alphabetical, the editor last.
- **Connect.** A brain that is installed and not known to be connected shows a **Connect** button on its seat's row: it starts the program's own login (the engine names the command, for Antigravity `agy acp --login`), the program opens the browser, and **Check again** asks whether it worked. A brain that cannot say whether it is logged in (Copilot) is offered it too. A seat whose brain is not connected shows *not connected* on its row.
- **The warning follows the seat.** A brain whose writes only an instruction holds back (Cursor-Grok, Antigravity) is offered to every seat; the Seats page says it cannot be restricted from writing only on a seat that must not change code, main and btw included. The engine does not prevent the choice.
- **One small status bar.** Under the window, the version each running engine reports (each workspace is its own engine process), and a line only where one differs from the installed version, so an engine started before an update finished and still running the old one is seen.
- **Brains are listed A to Z** by name on the Seats page.

## Known limits

- **Antigravity writes are not contained** (see jawata-mcp 4.6.14): a seat that must not write is only told so. Measured on `agy` 1.5.15.
- Connect splits the engine's login command on spaces and shows nothing if the login fails; the next check is the only signal. Recorded as a follow-up.
- The engine's roster and the studio's are still two copies of the same facts; adding Antigravity touched both. Recorded as a follow-up.
- Removing Grok leaves any jawata entry an earlier deploy wrote in a Grok config file in place; the studio does not retire it.
- **Not yet shown in a real window:** Connect with a real Antigravity login, the status bar against an engine that is really out of date, and the Seats page warning on a real main seat.
- Windows and macOS are run by CI, not by hand.
