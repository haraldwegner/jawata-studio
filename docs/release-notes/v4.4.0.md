# jawata-studio v4.4.0

**The guard stops hand edits where a tool exists, a typed command ends an autonomy grant, and the seats gain a UX designer you can call.**

This is the last 4.x release. It follows a measured refactoring sprint on a real codebase: the change tools were used twelve times, four of those changes were kept, and 47 of 298 hand edits afterwards had a working tool sitting unused. The guard now says so at the moment of the edit.

## What went wrong

- **A hand edit was refused only if it was undeclared.** The guard asked whether the agent had declared a reason, never whether a tool existed for the change, so 298 hand edits went by.
- **A hand-run measurement went through.** An agent downloaded a JaCoCo jar into the project and attached it from the shell while `run_tests` already collects the same evidence.
- **The guard carried one team's script names.** Two lists of our own build-script names were matched as text anywhere in a command, so it refused seven correct commands (a `sed` reading a script, a `grep` counting it in the binary, a commit message describing the rule).
- **A typed command did not end an autonomy grant**, and a command-shaped message could be read as a machine event.
- **The `ux` seat existed and nothing could call it.** No command, no phrase, no point in the dev process sent an agent to it, and the generated command would have told it to run a Java compile gate its own file says it is exempt from.
- **A path-valued assignment before a command** (`JAVA_TOOL_OPTIONS=-javaagent:/x/a.jar java …`) was read by every rule as the command.

## What changes

- **A hand edit of a `.java` file is refused by name where a tool performs the shape**: a changed import, visibility or parameter list on a declaration, a private member deleted, a declaration renamed, a range extracted. The refusal names the tool and the call. On the 312 hand edits of that sprint it refuses 24 of the 47 that had a tool, and none of the 94 new-code edits or 7 comment edits; the rest cannot be told apart from authoring by the edit's text alone and are closed by the roles below, not by a wider guess.
- **A declared exception covers one edit and must name the failure.** A second hand edit under the same declaration is refused, and so is a declaration with no named failure.
- **A hand-run coverage agent is refused** (fetched, attached, set through `JAVA_TOOL_OPTIONS`, or invoked as Maven's jacoco goal) and the refusal names `run_tests(coverage=true)`. An agent path held in a variable defined elsewhere, or a renamed jar, still passes; that is stated in the rule rather than hidden.
- **A script declares itself a long gate** in its own header, and the hook reads that where the command runs it. Our own build-script names are gone from the binary (third-party tools such as Maven and the Svelte checker are still matched as the program being run); a command that merely mentions a script is no longer refused. A long run is kept in a file, so a detail is read once rather than by a second run.
- **A typed command ends an autonomy grant**; a subagent hand-back and a background notification do not.
- **`/ux`** is a command, a plain-words phrase ("does the UI need this", "review this view") and a rule that sends the agent to it at any diff that changes a view. A seat that declares itself exempt from the gate rule is told so in its generated command. The roster sentence now counts what is true: the `/sprint` pair, the typed seats, and the seats the principal hires (PM and test manager).
- **The architect's checkpoint reports are gated.** Every report must carry a section saying what was asked of the experience store and the pattern catalogue and what was selected; the local gate run fails on one that does not.
- **The seats view and cleanup.** The PM and test-manager seats are defined; three of four planned settings are built.

## Known limits

- The hand-edit refusal covers 24 of 47 shapes at the text layer. An engine-side classifier would reach roughly 40; that is not in this release.
- The guard is installed over the previous one with a deploy; the old shell guard `guard-gate-output.sh` retires at that deploy.
- The seat command `/ux` reaches a machine at deploy, not at download.

Ships with jawata-mcp 4.4.0.
