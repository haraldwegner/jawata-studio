# jawata-studio v4.4.7

**The hook asks the engine for an occasion instead of a lane list, stops raising a false "event shape moved" alarm for the engine's own tools, runs its Windows tests again, and the Seats view's cards lose their shadow.**

## What went wrong

- **Every engine tool with ordinary arguments was logged as "the event shape moved".** Since the 4.4.6 install `hook_silence.log` held 109 such lines, for `experience` (with `format`, `kind`, `lane`, `limit`), `run_tests`, `compile_workspace`, `hire` and `data`. The hook cues a recall from a handful of input keys; the engine's tools take other arguments, and a reader was sent looking for a client change that had not happened.
- **Sixteen hook tests had been switched off on Windows,** so nothing proved the hook's path handling there.
- **Three of those tests were wrong on Windows, not the product:** one used `/no/such/dir`, which has no drive letter and is refused as relative; one ran `pwd`, which is not a Windows program; one cut the tests module at a line break a Windows (CRLF) checkout does not have, so test code was scanned as shipped.
- **The lists of lanes a hook asks were kept in two places,** the hook's and the engine's.
- **The Seats view scrolled slowly.**

## What changes

- **An engine tool called with a non-empty object of its own arguments is a silence for want of cues,** not a moved shape. The alarm stays for a host tool with an unknown field, a missing `tool_input` and an input that is not an object. "Engine tool" is read from the vendored engine surface.
- **The hook sends the engine an `occasion`** (typed message, tool call, recall gate, after a compaction, design question, does-it-exist) and the engine owns which lanes that asks. An engine that refuses the occasion is asked again by lane list, so a studio talking to an older engine keeps working.
- **The sixteen Windows tests are switched back on** and the three wrong ones are fixed. A build-only run of the release workflow was green on all five targets (Windows x64 and ARM, Linux x64 and ARM, macOS), the Windows jobs with 524 hook tests passed and none ignored.
- **The Seats view's cards lose their blurred shadow,** the candidate cause of the slow scroll.

## Known limits

- **The scroll fix is a candidate, not a proven cure.** It is judged by scrolling the installed window.
- **The lane-list fallback stays** until the release after this one has been in use; the table in the hook is still a second copy of the engine's.
- **The false-alarm fix has run only in tests;** the live check is that the silence log carries no "event shape moved" line for an engine tool after this is installed.

Works with jawata-mcp 4.4.12.
