# jawata-studio v4.6.10

**The conversations of a brain the engine started are marked machine-made, so History leaves them out.**

This release needs jawata-mcp 4.6.8.

## What you see

- **The History list in the chat shows the conversations you had in Claude Code and Cursor, and no longer the ones the engine started itself** (a hired seat, the principal's own brain). The hook that records a session now writes it under the client's name with "-machine" after it when the engine started that session; the engine's History leaves those out.

## Known limits

- Checked on Linux with the hook's tests. Sessions recorded before this release carry no mark; the engine tells those by their first words.
- Windows and macOS builds are produced but were not used by hand.
