# v3.14.3 — the story agents follow the Minto triad

Knowledge convinces the way a story does: **Situation → Complication → Solution,
and whether it worked.** The engine's v3.15.0 gave the complication — the CAUSE —
its own queryable field; this release teaches the two story agents to use it.

## /memorize writes the triad

The story-writing command's first rule is now the triad itself: each part goes in
its field — `situation:` (the setting and task), `cause:` (the diagnosis the
solution addresses; `complication:` is the same key), the claim plus its cure,
`verdict:`. The cause is not the symptom: a symptom is the observable (a fast
heartbeat), the cause is the problem behind it (running / a heart attack / a
virus) — one symptom, many causes, and the solution binds to the cause.

## /review checks and repairs it

The review seat's repair standard is the same triad. An entry with a situation
but no cause is the same class of repair as a missing situation: the seat lifts
the cause out of the entry's own text — it is usually the clause explaining WHY
the cure works — file-first, so the fix survives every rebuild. What it cannot
derive it parks for you; a cause is never guessed and never squeezed into a
wrong field.
