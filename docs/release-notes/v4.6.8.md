# jawata-studio v4.6.8

**The hook no longer hires a judge for your own conversation, and the Seats page, the brain check and every chat brain's model list come from the engine.**

This release needs jawata-mcp 4.6.7.

## What you see

- **jawata's hook no longer hires an observer to judge your own conversation.** The observer judge is deleted; the rule checks stay. The hook's autocontinue grant is the one state the engine also reads, so the chat's button, a typed `/autocontinue` and the hook agree.
- **The main and pm seats carry the engine's files, lookup and git tools, and the principal changes no code.** The seats' text says what the release order is: a release is ordered by `/release` or the bare word, not by a sentence that mentions it.
- **The Seats page, the brain check and the one-word test run read the engine's brains tool,** and a deploy asks the engine for every chat brain's models. The studio's own readers of the agent programs are deleted, so there is one list of brains and models, the engine's.
- **The hook's watch drops the retired judge's ledger line** and marks the report lines it still shows as history.

## Known limits

- Checked on Linux: the tests and the release checks. The installed studio window was not used for these changes, and the engine tools it now asks were checked against engine 4.6.7's published tool list. Windows and macOS builds are produced but were not used by hand.
