# jawata-studio v4.4.15

**A newer engine is tried before it replaces the one you use, and the check for one also runs when you stop or reload.**

## What went wrong

- **A newer engine was installed without ever being compared with this studio.** With "Always keep latest" the studio downloaded it and used it. The only comparison between the engine's tool list and the studio's copy ran in the studio's own release job, so an engine published later could retire or rename a tool, or add a code-changing one the studio's guard does not know, and nothing said so.
- **The check for a newer engine ran only when the studio started.**

## What changes

- **The trial:** a newer engine that would replace a working one is unpacked and started once on its own (the same start as Settings → Test services), and the tool list it publishes is compared with the studio's copy: the same tool names, the same code-changing flags, no retired name, and no tool the studio has never heard of. Only an engine that matches becomes the active one.
- **If it differs:** the installed engine stays active, Settings says how the new one differs (for example "the engine no longer offers: extract"), and the Download button refuses with the same reason. The refusal is remembered for that engine version and that studio version, so nothing is downloaded again until a newer engine or a newer studio exists.
- **When it runs:** the check for a newer engine also runs after Stop all, Reload all and stopping a single project, in the background and at most once every ten minutes. A new engine takes effect at the next start.
- **Proof against a real engine:** the whole trial was run against the published engine 4.4.16 (7 seconds, 44 tools, no difference); against a deliberately wrong copy of the tool list it reported the missing, the flipped and the new tool.

## Known limits

- **The comparison is strict.** An engine release that changes the tool list is held until a studio release carries the new list.
- **The first engine ever installed gets no trial,** because nothing is there to keep in its place.
- **The trial needs Java** on the machine and takes about 7 seconds.
- **Scrolling still stutters a little on every tab;** the painting-mode test is open.

Works with jawata-mcp 4.4.15 and 4.4.16.

## About 4.4.14

There is no 4.4.14 release: its build failed on Windows (a test helper was compiled out there), so nothing was published. 4.4.15 is the same change with that fixed.
