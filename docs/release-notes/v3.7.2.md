# jawata-studio v3.7.2

The hook binary now actually runs.

v3.7.0 and v3.7.1 deployed the six hook binaries to your client's config
directory and left every hook event invoking the old shell script. The binaries
sat on disk doing nothing. Found by the first dogfood probe after the release,
not by any gate.

This release points the client at the binary. Concretely, for you:

- **A hook that had silently stopped working now works.** Recall on tool calls
  produced nothing under the script; under the binary it injects the relevant
  prior knowledge. That was a feature the old generation had lost.
- **The hook says why it stayed quiet.** Every invocation records its reason —
  including a timeout, which previously left no trace at all and was
  indistinguishable from a hook that never ran.
- **The checks that keep the agent honest all moved across**, so nothing was
  lost in the switch: the audit-fix loop, the unjudged upward message, seat
  discipline, a length budget, and undefined jargon.
- **A message that is merely long now needs review before it is sent**, not only
  one that asks a question. Length does not depend on wording, which is why it
  catches what a phrase list misses.

An install that has not yet received a binary keeps using the script, so nothing
breaks mid-upgrade.
