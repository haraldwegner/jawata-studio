# jawata-studio v3.11.2

The health light is current when you look at it, the Field page is a Reporting
page, and the app runs from source again.

## The canary stops showing you a five-minute-old verdict

It probed once 45 seconds after startup and then every five minutes, blind —
no re-check when a resident started, restarted, or recovered. Measured on the
running fleet: after a resident restart both residents answered the canary's
own probes correctly, in under 200 ms, while the tray was still amber.

The wait now follows the answer. Green keeps the slow cadence; anything else is
re-checked in fifteen seconds. And a round can be asked for: starting or
stopping runtimes requests one, and so does opening the Reporting page —
someone looking at it is the strongest signal that the verdict should be
current. Requests collapse into one pending round, so an open page does not
become a probe every few seconds.

A resident that is still coming up still reads as not answering, and that is
deliberate: it genuinely is not answering yet. The change is that you stop
seeing it for minutes after it recovers.

## Field is now Reporting

The tab says what you do here; the page says what is on it. The seat lane is
gone — seats get their own place in a later release — and the two things worth
keeping came with it into the header: what `/report` does, and the go-silent
switch.

Go silent is per MACHINE now. It was per workspace, which was an implementation
detail of where the state file lives leaking onto the screen: you report tool
failures for jawata, not for one workspace and not the other.

The page's text is shorter throughout. Nothing that carries meaning was cut —
the sanitization promise, the client caveat on the utilization number, and the
"the real share can only be higher" clause all stay.

## Running from source works again

Two defects, both invisible to the test suite because tests never invoke
`cargo run` or the dev server:

- `npm run tauri dev` could not start at all — the crate gained a second
  binary when the hook became a workspace sibling, and cargo refused to choose.
- Once it started, the window came up WHITE: the dev server was watching
  `src-tauri/target`, 143,000 build artifacts against an OS watcher limit of
  65,536, so it died and the window had no frontend to load.

## Groundwork, stated as groundwork

The recall gate is wired to the tool-recall path and ships in OBSERVE: when a
stored record is anchored at exactly the symbol a tool call is about, it
records that it would have asked you to say what you did with it — and does not
block. It fails open at every step; an unreachable knowledge layer never holds
a call.
