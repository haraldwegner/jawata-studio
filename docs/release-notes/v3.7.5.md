# jawata-studio v3.7.5

One line from the Cursor dogfood re-run: a denied command now always names the
way out.

When the Cursor guard blocks a java text search, the message the client shows
depends on which of two fields it surfaces — and the hint that a declared
`jawata-fallback: <why>` proceeds lived in only one of them. Whoever saw the
other field got "Blocked" with no legitimate escape named. Both fields now
carry the hint, and the test asserts each field separately.
